Sentry found a path traversal vulnerability (CVE-2026-20685) in Apple's Private Cloud Compute and was able to write files with root privileges without authorization, redirecting confidential AI telemetry data and inference metadata to their own server. Apple's cryptographic attestation did not detect the tampered configuration files on the writable data volume. I'll be honest, I'm not deep enough in the topic to describe it any better than that.
- https://blog.sentry.security/beyond-prompt-injection-hacking-apples-private-cloud-compute/
